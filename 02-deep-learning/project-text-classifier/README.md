# Mini Project: RNN 텍스트 감정 분류기

## 목표
RNN/LSTM을 사용하여 텍스트 감정 분류기를 구현하고 학습시키기.

## 요구사항
1. 데이터셋: IMDB 영화 리뷰 (긍정/부정)
2. 구현 항목:
   - 텍스트 전처리 (토큰화, 패딩, 어휘 사전)
   - Embedding → LSTM → FC 아키텍처
   - 학습 루프 (train/val split)
3. RNN vs LSTM 성능 비교
4. 학습 과정 시각화 (loss, accuracy)
